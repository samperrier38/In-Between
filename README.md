# In Between

## Project Option
Website

## Project Description
In Between is an interactive website that explores the importance of communication and meaningful relationships. The website encourages users to reflect on how small acts of kindness and understanding can strengthen connections between people. Through interactive buttons and reflection prompts and users are invited to think about ways they can build stronger relationships in their own lives.

## Theme Interpretation
The theme of Space is interpreted as the emotional and relational space that exists between people rather than outer space. The website explores how this space can either separate people or become a place where trust and understanding grow through communication.

## Intended User
This website is designed for teenagers and young adults who are interested in building healthier relationships and reflecting on the importance of communication and connection.

## User Goal
The goal is for users to explore the website, learn about the importance of connection, interact with the reflection activities, and leave with a better understanding of how they can strengthen relationships with others.

## Main Features
- Responsive single-page website
- Navigation bar for easy access to each section
- Hero section introducing the website
- About section explaining the purpose
- Connection section with information about building relationships
- Reflection section with an interactive message
- Call-to-action section encouraging users to reach out to someone
- Footer with project information

## JavaScript Features
JavaScript adds interactivity to the website through multiple user interactions. The Learn More button reveals additional information about relationships. The Reflection button displays and hides an inspirational quote using a function and conditional logic. The Call-to-Action button provides encouraging feedback after the user chooses to reach out to someone. The project uses variables, functions, event listeners, conditionals, and visible interface updates.

## Responsive Design
The website uses flexible layouts, scalable images, and a media query to adapt to different screen sizes. Navigation stacks vertically on smaller screens, buttons resize for easier use on mobile devices, and content remains readable without horizontal scrolling.

## User Testing
The website was tested by classmates on different screen sizes and browsers. Testers were able to navigate through each section and complete the interactive elements. Feedback suggested making the navigation clearer, improving spacing between sections, and making buttons more noticeable.

## Revisions
Based on user testing, the following improvements were made:
- Added a fifth content section and improved navigation.
- Increased spacing and improved the layout for better readability.
- Added additional JavaScript interactions and improved button feedback.
- Improved responsive behavior for smaller screens.
- Added more images and descriptive alternative text for accessibility.
